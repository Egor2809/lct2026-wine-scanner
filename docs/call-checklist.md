# Чек-лист на созвон с жюри

Сервис запускается на Mac локально, без Docker: так быстрее, и работает
Apple Vision как запасной OCR. Docker — запасной путь.

## За 15 минут до созвона

Сначала убедиться, что машина свободна: занятый CPU раздувает латентность.
Если включён Yandex OCR, его квота (~1 запрос/с) общая на ключ: параллельные
прогоны с тем же ключом дают 429.

```bash
ps aux | grep -i -E "uvicorn|python" | grep -v grep   # нет лишних тяжёлых процессов
uptime                                         # load average низкий (< 2–3), не 8+
```

```bash
cd ~/Desktop/projects/MOS
lsof -ti :8080 | xargs kill 2>/dev/null        # старые процессы на порту
source .venv/bin/activate
# HF_HUB_OFFLINE: веса SigLIP уже в кэше, без него старт без сети ждёт таймауты хаба
HF_HUB_OFFLINE=1 PYTHONPATH=src uvicorn wine_scanner.api.app:app --host 0.0.0.0 --port 8080
```

В логе старта должна быть строка `Пайплайн готов за … c: каталог 1…, индекс 1…,
… OCR yandex-ocr|apple-vision`. Потом во втором терминале:

```bash
curl -s localhost:8080/health                  # {"status":"ok", ...}
python scripts/evaluate.py --labels data/field/labels.csv --url http://127.0.0.1:8080/scan \
    --min-top1 0.952 --max-p95 1500             # ПРИЁМКА: OK
```

Оригинальный скрипт организаторов — ровно их командой из README (порт 8080
у них по умолчанию). Ожидание: 3 строки, `predicted_slug` не `null`.

```bash
cd ~/Desktop/projects/MOS/vino_unpacked/RSHB_VINO/data/eval
rm -f /tmp/rshb_check.jsonl
chmod +x participant_test.sh
./participant_test.sh \
  --images-dir ./queries \
  --manifest ./queries.tsv \
  --endpoint 'http://127.0.0.1:8080/v1/eval/predict' \
  --output /tmp/rshb_check.jsonl
jq -c '{query_id, predicted_slug, latency_ms}' /tmp/rshb_check.jsonl
cd ~/Desktop/projects/MOS
```

Открыть `http://127.0.0.1:8080/` в браузере, снять одну бутылку телефоном.
Режим сна выключить: `caffeinate -dims &`.

## Маршрут демо (2 минуты)

1. Сканер → фото из каталога (например `data/field/68.81_05-09-2026_15-46-31.webp`,
   Фанагория Velvet Season) → сразу одна карточка, без экрана вариантов.
2. На карточке: «На портале» ведёт на настоящую страницу vino-svoe.ru; ниже —
   аналоги других виноделен. Тап по винодельне → все её вина из каталога.
3. Вино вне каталога (любое из `data/field/out_of_catalog.csv`) → «Точного
   совпадения нет», до 5 вариантов и аналоги других виноделен — пункт ТЗ,
   который «оценивается особенно высоко».
4. Сомелье: 3 вопроса → вина разных хозяйств из каталога; если сочетание
   фильтров пустое, он ослабляет их и прямо об этом пишет.
5. Каталог: поиск и фильтры по стилю и региону — модуль «живёт» в каталоге.

## Если что-то упало

| Симптом | Что делать |
|---|---|
| `/health` → 503, `loading_failed` | Причина — в поле `error`. Обычно нет `artifacts/index.npz` (`python scripts/build_index.py`, ~3 мин) или индекс собран другим эмбеддером |
| `Address already in use` | `lsof -ti :8080 \| xargs kill`, запустить заново |
| В логе `Yandex OCR отклонил ключ (401)` | Ключ протух или не тот каталог. Сервис уже работает на Apple Vision — отвечать дальше. Починить: исправить `.env`, перезапустить (старт ~20 с) |
| В логе `yandex-ocr недоступен … читаю через apple-vision` | Нет сети или 429. Ничего не делать: облако само пробуется снова через 30 с (после 429 — через 3 с) |
| Нет сети совсем | Сервис работает на Apple Vision + картинке, точность почти та же |
| Ответ с полем `error` | Файл не картинка или не декодируется. Сервис всё равно вернул slug, это не падение |
| Процесс умер | Перезапустить той же командой; старт ~20 с. Индекс и модели лежат на диске |
| Mac не вытягивает | Запасной путь: `docker compose up -d`, ждать `healthy` в `docker compose ps` (~1–2 мин) |

## Что говорить, если спросят

- Ответ — плоский JSON, `slug` в корне, никогда `null`: при любом сбое
  возвращается позиция каталога с `confidence: 0` и полем `error`.
- Модель и индекс грузятся на старте (lifespan), первый запрос не ждёт прогрева.
- Облачный OCR уложен в 1,6 с вместе с повторами; при сбое предохранитель
  выключает его на 30 с, и запросы идут в Apple Vision (macOS) или только
  по картинке (Linux/Windows). Запрос не длиннее 3 с.
